Privacy Policy — OpenClaw Agent

Last updated: 9 October 2026

This application is a private, single-user tool operated by and for Frederick Penny. It is not offered to the public, has no other users, and does not collect data from anyone else.

Information accessed

With the account owner’s explicit consent, the application accesses only data belonging to the same Google account that granted access:

  • Gmail — read-only access to messages.
  • Google Calendar — read and write access to events.
  • Google Drive, Docs, Sheets and Slides — read and write access to the account’s files.

How it is used

Data is used only to perform tasks the owner requests — for example reading a confirmation email or updating a calendar event’s location. Nothing is sold, shared, or transferred to any third party.

Storage

OAuth credentials are stored locally on the owner’s own computer. Message and file content is processed in memory to complete the owner’s requests and is not retained on any external server.

Data retention and deletion

The application does not maintain its own copy of the account’s data. Access can be revoked at any time from the Google Account permissions page, which immediately ends the application’s access.

Changes

This policy may be updated to reflect changes in the tool. The “last updated” date above reflects the most recent version.
